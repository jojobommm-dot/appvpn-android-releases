# AppVpn для Android

VPN-клиент для Android 8 и новее. Здесь лежат только готовые сборки.

## Установка

1. Откройте на телефоне [последний выпуск](https://github.com/jojobommm-dot/appvpn-android-releases/releases/latest)
   и скачайте файл `appvpn-….apk`.
2. Откройте скачанный файл. Если телефон спросит, разрешите установку из этого источника
   (браузера или «Файлов»), затем нажмите «Установить».
   Приложение не из Play Маркета, поэтому «Google Play Защита» может его остановить
   («Приложение заблокировано…» или «Рекомендуется проверка»): нажмите «Подробнее» →
   «Все равно установить» (или «Установить без проверки»).
3. В приложении: «Серверы» → «Добавить». Вставьте ссылку или адрес подписки, который вам
   прислали, или отсканируйте QR-код.
4. На «Главной» нажмите большую кнопку и разрешите подключение VPN.

## Обновления

Приложение само проверяет новые версии. Когда выйдет новая, на «Главной» появится кнопка
«Обновить». В первый раз Android попросит разрешить установку из AppVpn — включите и
нажмите «Обновить» ещё раз. «Play Защита» может снова спросить — как в шаге 2.

## Что умеет

- Протоколы VLESS, Trojan, Hysteria2, TUIC и AmneziaWG 3.1.
- Российские сайты открываются напрямую, мимо VPN (можно выключить в «Настройках»).
- Выбранные приложения ходят в интернет без VPN («Приложения»).
- Плитка в шторке быстрых настроек.
- Подключение при включении телефона.
